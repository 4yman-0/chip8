Assembler, disassembler and emulator for CHIP-8 and SCHIP.

 - `asm`: Assembler with custom syntax (not Octo's).
 - `disasm`: Disassembler with custom syntax (not Octo's).
 - `terminal`: Emulator for terminals (tested on Linux).
 - `chip8-op`: Library for representing CHIP8 instructions.
